# تقاطع المعرفة

مسابقة كلمات متقاطعة بين الأقسام العلمية السبعة في كلية الإدارة والاقتصاد، جامعة الموصل.

## طريقة التشغيل

افتح الملف `index.html` في المتصفح. اللعبة ملف واحد ولا تحتاج تثبيتاً.

## القواعد

- قبل كل مباراة يختار القسمان أنواع الأسئلة: رياضة، فن وأدب، علوم، منوّع، ومحاور الكلية.
- تُولَّد شبكة كلمات جديدة من الأنواع المختارة.
- يتناوب القسمان. يختار القسم كلمة، ثم يبدأ وقت الإجابة.
- الإجابة الصحيحة: نقطة عن كل حرف كان مخفياً في الكلمة.
- الإجابة الخاطئة أو انتهاء الوقت: يُكشف حرف من الكلمة وينتقل الدور.
- البطولة بنظام خروج المغلوب مع قرعة عشوائية.

## الحقوق

- فكرة المسابقة: د. عمر فاروق يونس، مدير شعبة الأنشطة الرياضية / كلية الإدارة والاقتصاد - جامعة الموصل
- تصميم وبرمجة: علي عبد الوهاب الصفار
